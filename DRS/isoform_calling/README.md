## ORDER OF OPERATIONS

1. Run `count_map.sh` to use `make_count_maps.py` to convert file of individual reads into table of number of reads ending at each pair of genomic coordinates. Splits maps into genomic sections to allow downstream paralellization, such that no isoform is expected to cross multiple sections.

2. Run `normalize_runner.sh` twice with different winsorizations to do 2D Z-score normalization of all count maps. Winsorization values to use: `0` (no winsorization) and `0.1` (90% winsorization). The `normalize_runner.sh` script will start a number of parallel jobs using `normalize_jobs.sh` to process each genomic region simultaneously.

3. Run `filter.sh` to 1) remove everything shorter than 200 nt and 2) remove all coordinate pairs with Z-scores below an input threshold. We used a Z-score threshold of `30`. This will generate filtered lists of coordinates for each winsorization setting.

4. Run `cluster.sh` to cluster together nearby points that all meet the Z-score threshold using single linkage agglomerative clustering. We used a distance threshold of 4, chosen using the dendrograms output by the `cluster_isoforms.py` script. This script generates a list of clusters for each winsorization setting, with the coordinate pair that has the greatest number of counts in the cluster serving as the identifying coordinate.

5. Run `combine.sh` to collapse the two winsorization settings into one map by only retaining coordinates identified with 90% winsorization if they are distinct from those identified without winsorization and have another coordinate pair within their Z-score window.

6. Run `all_gene_match.sh` which will combine the lists of isoforms from each distinct timepoint generated by the last step into a single list and match them with the genes they 1) fully cover and 2) overlap by at least 1 nt with.

7. Run `isoform_quant.sh` to quantify reads corresponding to each isoform.

8. Run `combine_norm_counts.sh` to combine all isoforms into one file and normalize isoform counts by stable normalization RNAs.
